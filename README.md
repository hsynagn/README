- **Adet Takvimi Regl AI:** Adet döngüsü takibi ve yapay zekâ destekli sohbet özellikleri üzerine geliştirilen mobil uygulama.

- **Garajım AI:** Araç bilgileri ve otomotiv odaklı yapay zekâ özellikleri üzerine proje fikri.
